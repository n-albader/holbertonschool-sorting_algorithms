# Sorting Algorithms

This project contains implementations of different sorting algorithms
and Big O notations for their time complexity.

## Algorithms

The project covers different sorting algorithms, including:

- Bubble sort
- Insertion sort
- Selection sort
- Quick sort
- Shell sort
- Cocktail shaker sort
- Counting sort
- Merge sort
- Heap sort
- Radix sort
- Bitonic sort

## Data Structures

The project uses the following data structures:

- Arrays of integers
- Doubly linked lists
